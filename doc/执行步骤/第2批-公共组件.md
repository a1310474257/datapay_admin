## 四、各组件规格

### 4.1 `components/StatusTag/index.vue`

**Props**：

| prop | type | 说明 |
|---|---|---|
| `dict` | `Object` | 来自 `utils/enums.js`，如 `ORDER_STATUS` |
| `value` | `number \| string` | 当前值 |

**实现**：查 `dict[value]` 得 `{ label, type }`，渲染 `<el-tag :type="type">{{ label }}</el-tag>`；查不到降级为 `—`。

### 4.2 `components/PriceInput/index.vue`

**Props**：

| prop | type | 说明 |
|---|---|---|
| `modelValue` | `Number`（整数分） | v-model |
| `min`, `max` | `Number`（分） | 可选 |
| `precision` | `Number` | 默认 2 |
| `placeholder` | `String` | — |

**实现**：

- 内部用 `ref` 保存显示值（元，字符串）
- `watch(modelValue, ...)` 用 `fen2yuan` 同步内部
- 失焦/change 时用 `yuan2fen` 计算 emit `update:modelValue`
- 展示 `<el-input-number>` 或 `<el-input>` 加 "¥" 前缀，`:precision="precision"`
- 防止用户输入负数、超限

### 4.3 `components/DictSelect/index.vue`

**Props**：

| prop | type | 说明 |
|---|---|---|
| `dictKey` | `'category' \| 'teacher' \| 'express'` | 必填 |
| `modelValue` | `Number \| Array` | v-model |
| `filterable` | `Boolean` | 默认 true |
| `multiple` | `Boolean` | 默认 false |

**实现**：

### 4.4 `components/UploadImage/index.vue`

**Props**：

| prop | type | 说明 |
|---|---|---|
| `modelValue` | `String`（url） | v-model |

## 五、组合式 Hook

### 5.1 `hooks/useTable.js`

```js
export function useTable({ loadApi, defaultParams = {} }) {
  const tableRef = ref(null)
  const searchParams = reactive({ ...defaultParams })
  const loadData = (params) => loadApi({ ...searchParams, ...params })
  const onSearch = () => tableRef.value?.refresh()
  const onReset = () => { /* 重置 searchParams 并触发 refresh */ }
  return { tableRef, searchParams, loadData, onSearch, onReset }
}
```

### 5.2 `hooks/useDict.js`

```js
export function useDict(key) {
  const store = useDictStore()
  const options = computed(() => store[key])
  onMounted(() => store[`load${capitalize(key)}`]?.())
  return { options }
}
```

### 5.3 `hooks/useUpload.js`

封装上传动作：统一 Mock / 真实两套实现，返回 `{ uploading, upload(file, folder) }`。Mock 实现延时 300ms 返回 picsum 固定链接。

## 八、实现约定（统一风格）

1. **所有组件用 `<script setup>`**，配合 `defineProps / defineEmits / defineExpose`
2. **样式 scoped**，必要时用 `:deep()` 覆盖 Element Plus
3. **v-model 约定**：`modelValue / update:modelValue`；多模型用 `v-model:xxx`（如 `UploadImage` 可用默认 `modelValue` 为 url）
4. **组件根元素加 class** 以 `dp-` 前缀，方便项目级覆盖
5. **不在组件内写死业务逻辑**，通过 Props/Slot 暴露
6. **ProTable 的 loadData** 必须接受 `params` 并返回 Promise，让调用侧可控
7. **表单校验**：`<el-form :rules>` 方式，由调用侧传入 rules；组件不硬编码
8. **单一职责**：`UploadImage` 只管单图，多图走第 4 批的 `UploadImageList`

## 九、交接给第 3 批的契约

1. **`ProTable` 的 Props/Expose 定型**：特别是 `loadData(params)` 的 params 结构、`refresh()` / `setParams()` 方法
2. **`SearchForm` 的 schema 形态**：`{ prop, label, type, options, placeholder, span }`
3. **`StatusTag` / `DictSelect` / `UploadImage` / `PriceInput` / `RichEditor`** 的 Props 稳定
4. **`useTable()` 返回值结构稳定**
5. 组件目录与导入路径稳定：`import ProTable from '@/components/ProTable/index.vue'`

## 十一、风险与注意事项

| 风险 | 应对 |
|---|---|
| wangEditor 样式穿透 | 按官方文档引入 `@wangeditor/editor/dist/css/style.css` |
| ProTable 二次封装过度 | 保持 slot + expose 简洁，未来扩展用 slot 优于加 prop |
